# Contributing

OpenKaggle welcomes reproducible code, research notes, and careful corrections.
Do not commit credentials, restricted organizer data, or third-party files
without a clear redistribution license. Prefer official links, hashes, and
derived evidence.

## Cite this repository

Use GitHub's **Cite this repository** action, or copy the canonical entry from
[`CITATION.bib`](CITATION.bib) / [`CITATION.cff`](CITATION.cff).
